To Sysprep a Windows 11 reference PC for Steadier State:

Easiest: run prepref.cmd (in the root of this repository) from an elevated
command prompt. It checks UEFI, edition, BitLocker, hibernation and then
offers to run Sysprep with unattend-win11.xml.

Manually:

1) Log on as an administrator and open an elevated command prompt.
2) Make sure BitLocker / Device Encryption is OFF:
       manage-bde -status C:          (must say "Fully Decrypted")
       manage-bde -off C:             (if it doesn't, then wait)
3) Run:
       %windir%\System32\Sysprep\sysprep.exe /generalize /oobe /shutdown /unattend:G:\Sysprep\unattend-win11.xml
   where G: is wherever this folder lives.
4) If Sysprep fails, read %windir%\System32\Sysprep\Panther\setuperr.log.
   The common Windows 11 cause is a per-user Store app; remove it with
       powershell "Get-AppxPackage -AllUsers *AppName* | Remove-AppxPackage -AllUsers"
   and run Sysprep again.

DO NOT LET THE SYSTEM BOOT FROM THE HARD DISK after Sysprep shuts it down.
Boot it from the Steadier State USB stick and run cvt2vhd.
